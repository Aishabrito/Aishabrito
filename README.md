### Ferramentas

- **Linguagens:** TypeScript, JavaScript
- **Interface:** React, React Native com Expo, Next.js, Tailwind, Figma
- **Servidor e dados:** Node, Express, PostgreSQL com Prisma, MongoDB, Firebase, Supabase
